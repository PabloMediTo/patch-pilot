# Publish approved GitHub proposals

## Objective

Publish only approved change proposals as idempotent GitHub branches and linked draft pull requests, with reconciled delivery state.

## Key Results

- [ ] Repeated delivery attempts cannot create duplicate branches or pull requests.
- [ ] Draft pull requests include issue linkage, plan, scope, and verification evidence.
- [ ] GitHub webhooks reconcile remote delivery state into the run timeline.
