# Autonomous GitHub Maintainer

The Autonomous GitHub Maintainer turns one supported GitHub issue into a small, tested, human-reviewed pull-request proposal.

The product is about controlled maintenance work rather than unconstrained code generation. Every run exposes its evidence and decisions through a visible sequence: inspect, reproduce, plan, modify, test, critique, retry when justified, and wait for human approval before publishing changes.

The product docs separate intent, workflow, system composition, and MVP limits so each can evolve without blending independent decisions.
